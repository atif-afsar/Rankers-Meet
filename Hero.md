# HERO SECTION REDESIGN — YASIR ALI CLASSES
## Rankers Meet 2026

## Objective

Redesign ONLY the hero section of the Rankers Meet 2026 landing page.

The current hero feels visually crowded because of:
- Too many floating avatars
- Multiple circular orbit lines
- Reaction bubbles
- Random icons
- Excessive decorative elements
- Too many visual focal points

Replace it with a much cleaner, minimal, premium and highly polished hero.

The hero should immediately communicate:

"Yasir Ali Classes presents Rankers Meet 2026"

The design should feel:
- Premium
- Academic
- Elegant
- Modern
- Minimal
- Trustworthy
- Celebration-oriented
- High-end education event

Do NOT make it look like a generic SaaS website.

---

# IMPORTANT DESIGN DIRECTION

Use the existing website's visual language:

Primary:
- White background
- Deep navy / almost-black typography
- Yasir Ali Classes red as the primary accent
- Very subtle light-gray borders
- Extremely subtle shadows

Avoid:
- Dark hero backgrounds
- Neon colors
- Futuristic UI
- Excessive gradients
- Glassmorphism
- Floating social media reactions
- Random profile pictures
- Large orbital circles
- Excessive 3D objects
- Over-decoration

The visual hierarchy must be extremely clear.

# ANIMATION

The animation should feel premium and restrained.

## On page load

1. Announcement label fades in.
2. Headline slightly moves upward and fades in.
3. "2026" reveals with a subtle red accent animation.
4. Supporting text fades in.
5. CTA slides upward 8–12px and fades in.
6. Event metadata appears last.
7. Background circle slowly draws itself.

Animation duration:
0.5–0.9 seconds per element.

Use staggered animation.

Do NOT use:
- Bounce
- Elastic animation
- Excessive scaling
- Spinning
- Fast particle explosions
- Large parallax movement

---

# CONTINUOUS ANIMATION

Only background elements should continuously move.

Example:

Large circular outline:
slow rotation or extremely subtle breathing effect.

Duration:
30–45 seconds.

Amplitude:
very small.

Trophy:
slow 3px floating animation.

Dots:
very subtle opacity changes.

The text itself should remain stable.

---

# SCROLL INTERACTION

As the user scrolls:

The hero should subtly move upward.

Headline can move approximately:
10–20px.

Background circle:
slightly slower parallax.

Do NOT create extreme parallax.

The page should remain smooth on mobile.

Use performant transforms only.

Avoid expensive scroll handlers.

Prefer:
requestAnimationFrame
or existing animation utilities in the project.

---

# CTA INTERACTION

Desktop hover:

Button moves:
1–2px upward.

Arrow moves:
4–6px to the right.

Shadow increases very slightly.

Mobile:

Use a subtle press animation.

No excessive animation.
